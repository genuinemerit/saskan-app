# Saskan i18n – Spanish (Castilian) Style Guide

**Audience:** General users in Spain. Avoid Latin American regionalisms unless neutral. Tone: clear, concise, system-message style.

## 1. Vocabulary

* **Reject / unsupported:** use **“no admitido/a”** (*no admitida*, *versión no admitida*), not *“no soportado/a”*.
* **Invalid:** use **“no válido/a”** (*solicitud no válida*).
* **Reject / deny:** prefer **“rechazado/a”** over *“denegado/a”* (the latter sounds legal/bureaucratic).
* **Server ready:** *“servidor listo”* or *“servidor disponible”* (avoid *“preparado”*, which can sound odd).

## 2. Register / tone

* Use **imperative / indicative simple**:

  * *“Conexión rechazada.”* (not *“La conexión ha sido rechazada”* → too wordy).
* Avoid overly colloquial words. Aim for **technical clarity**.

## 3. Grammar / spelling

* Capitalization: sentence-case only (*“Conexión rechazada.”*), no Title Case.
* Accents matter (*versión, válido, está*).
* Gender agreement: *solicitud* is feminine → *no válida*.

## 4. Consistency

* Use the same subject consistently:

  * **Handshake rejected** → *“Conexión rechazada”*
  * **Request invalid** → *“Solicitud no válida”*
* Do not mix synonyms (*rechazado / denegado*); pick one term family and stick to it.

## 5. Style examples

* **EN:** Handshake rejected: unsupported protocol version.
  **ES:** *Conexión rechazada: versión de protocolo no admitida.*

* **EN:** Handshake rejected: invalid request.
  **ES:** *Conexión rechazada: solicitud no válida.*

* **EN:** Handshake rejected: server is not ready.
  **ES:** *Conexión rechazada: el servidor no está listo.*

* **EN:** Welcome to the Saskan Lands.
  **ES:** *Bienvenido a las Tierras Saskan.*
