# NDJSON (Newline-Delimited JSON)

Stream‑friendly format: one complete JSON value per line, each line terminated by `\n`. Works well with Unix tools and log pipelines.

- Rules: no pretty‑printing across lines; escape newlines inside strings (`\\n`).
- Authoring: usually generated by code; for manual tests, paste a compact JSON and press Enter once.
- Example:

```
{"id":"1","name":"system.handshake.request","meta":{"protocol":"0.1.0"},"payload":{"client_version":"0.1.0"}}
{"id":"2","name":"system.welcome","meta":{"protocol":"0.1.0"},"payload":{"server_version":"0.1.0","session_id":"…","motd":"Welcome"}}
```
