# Pull Request (PR)

A request to merge changes from one branch into another (e.g., feature → main), with discussion, reviews, and automated checks.

- Includes: source/target branches, diff, metadata (title, description, labels), CI checks, and review thread.
- Lifecycle: open PR → CI runs → review/approve → merge (squash/rebase/merge commit).
- See also: [Merge Strategies](merges.md)
