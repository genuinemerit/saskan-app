# Quality of Service (QoS)

The delivery guarantees and performance expectations a system provides for messages.

- Delivery: at‑most‑once (may drop), at‑least‑once (retries; duplicates possible), exactly‑once (expensive).
- Ordering: preserve send order or not.
- Durability: survive crashes/restarts.
- Prioritization: latency/bandwidth for important messages.
